# Modul Praktikum 1 — Logika dan Himpunan

**Tema besar:** Berpikir Logis dan Memodelkan Informasi<br>
**Cakupan:** Pertemuan 1–4

## Deskripsi

Modul ini memperkenalkan cara menyatakan masalah secara formal menggunakan logika dan himpunan, kemudian menerjemahkannya menjadi algoritma serta program Python. Setiap pertemuan memadukan teori, praktikum, problem based learning (PBL), latihan, dan refleksi.

## Capaian Pembelajaran

Setelah menyelesaikan modul, mahasiswa mampu:

- menjelaskan proposisi, operator logika, predikat, dan kuantor;
- membangun serta menganalisis tabel kebenaran;
- menerapkan operasi himpunan dan himpunan dalam Python;
- memodelkan masalah seleksi menggunakan logika dan himpunan;
- menulis, menguji, dan mendokumentasikan program Python sederhana.

## Prasyarat dan Perangkat

- Python 3.10 atau lebih baru
- VSCode
- terminal untuk menjalankan program

Verifikasi instalasi:

```bash
python --version
```

## Alur Pengerjaan

```text
Masalah → Identifikasi variabel → Model logika/himpunan
→ Algoritma → Implementasi Python → Testing → Dokumentasi
```

## Ketentuan Pengumpulan

Setiap pekerjaan dikumpulkan dalam folder pertemuan terkait dan minimal memuat:

- analisis masalah dan asumsi;
- model logika atau notasi himpunan;
- pseudocode;
- program Python;
- bukti pengujian dan kesimpulan.
