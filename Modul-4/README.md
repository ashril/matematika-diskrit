# Modul Praktikum 4 — Project Based Learning

**Tema besar:** Integrasi Matematika Diskrit dalam Pemecahan Masalah Nyata<br>
**Cakupan:** Pertemuan 13–16

## Deskripsi

Modul ini adalah puncak dari mata kuliah Matematika Diskrit. Mahasiswa tidak diperkenalkan banyak teori baru, melainkan **mengintegrasikan seluruh konsep dari Modul 1–3** untuk membangun solusi atas masalah nyata dalam dunia teknologi informasi.

Fokus utama:
- Kemampuan mengubah masalah → model matematika diskrit
- Merancang algoritma yang tepat
- Mengimplementasikan solusi dalam Python
- Mengevaluasi dan mendokumentasikan hasilnya

## Capaian Pembelajaran

Setelah menyelesaikan modul, mahasiswa mampu:

- mengidentifikasi masalah nyata yang dapat dimodelkan dengan matematika diskrit;
- memilih dan menggunakan konsep yang tepat (logika, himpunan, relasi, fungsi, teori bilangan, atau graf);
- merancang algoritma dari model matematika;
- mengimplementasikan solusi lengkap dalam Python;
- melakukan testing, debugging, dan evaluasi algoritma;
- mendokumentasikan dan mempresentasikan proyek secara ilmiah.

## Prasyarat

- Menguasai materi Modul 1, 2, dan 3
- Python 3.10+, NumPy, Matplotlib, NetworkX
- Kemampuan menulis pseudocode dan dokumentasi
